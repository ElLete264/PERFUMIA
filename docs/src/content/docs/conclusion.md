---

PerfumIA es una aplicacion web completa que une frontend responsive, backend seguro, base de datos relacional, APIs externas, inteligencia artificial, pruebas y documentacion.

## Que se ha conseguido

- Registro, login local y Google Login.
- Seguridad con JWT y rutas protegidas.
- Perfil visual personalizado.
- Foto de perfil con Cloudinary.
- Chat conversacional con Gemini y fallback local.
- Busqueda de perfumes con Fragella y catalogo local.
- Recomendaciones Top 3.
- Scoring determinista sin azar.
- Filtro por presupuesto, genero, temporada, ocasion, intensidad, notas y notas rechazadas.
- Historial de aceptados y rechazados.
- Favoritos y ratings.
- Comunidad con mensajes y perfiles publicos.
- Documentacion Starlight con diagramas obligatorios.
- Tests automaticos de backend.

## Aprendizajes DAW aplicados

El proyecto aplica conocimientos de frontend, backend, servicios REST, persistencia, autenticacion, autorizacion, integracion con APIs, validaciones, testing, documentacion y preparacion de despliegue.

## Parte diferencial

La parte mas diferencial es la integracion de Gemini con una logica propia de recomendacion. Gemini permite conversar de forma natural, pero el backend mantiene el control sobre filtros, scoring, presupuesto, historial y explicaciones.

## Mejoras futuras

- Despliegue completo con dominio definitivo.
- Enlace de compra en cada perfume recomendado para llevar al usuario a una tienda o ficha externa.
- Mas datos reales sobre duracion, sillage y popularidad.
- Busquedas indexadas.
- Resenas de usuarios.
- Panel de administracion.
- Tests end-to-end con Playwright.
- Automatizacion de despliegue con GitHub Actions.

## Cierre

PerfumIA es defendible como proyecto final DAW porque no solo implementa funcionalidades aisladas, sino una experiencia completa y coherente. El usuario puede entrar desde movil, conversar, recibir recomendaciones razonadas y guardar sus perfumes, mientras el proyecto demuestra arquitectura, seguridad, persistencia, integraciones y documentacion.
