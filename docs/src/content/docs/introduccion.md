PerfumIA es una aplicacion web recomendadora de perfumes creada como proyecto final de Desarrollo de Aplicaciones Web. Permite que una persona se registre, inicie sesion y converse con un asesor olfativo inteligente para encontrar perfumes adecuados a su gusto.

La idea principal es evitar que el usuario tenga que navegar por un catalogo enorme sin saber que buscar. PerfumIA pregunta de forma progresiva por genero, estacion, ocasion, intensidad, presupuesto, notas favoritas, notas rechazadas y estilo personal.

## Justificacion

Elegir un perfume puede ser complicado porque los usuarios no siempre conocen conceptos como familia olfativa, sillage, notas de salida, notas de fondo o diferencias entre fragancias frescas, dulces, amaderadas o especiadas.

PerfumIA resuelve ese problema con una experiencia conversacional. El usuario puede escribir frases naturales como "no entiendo de perfumes, pero quiero algo que huela a fresa" y el sistema transforma esa respuesta en parametros tecnicos.

## Objetivos

- Crear una aplicacion full stack funcional.
- Implementar autenticacion local y con Google.
- Proteger rutas privadas mediante JWT.
- Usar una base de datos relacional consistente.
- Integrar Gemini para mejorar la conversacion.
- Integrar Fragella como catalogo externo de perfumes.
- Mantener fallback local cuando una API externa no este disponible.
- Recomendar perfumes con un sistema explicable y sin azar.
- Crear una interfaz usable desde escritorio y movil.
- Documentar el proyecto con README y Starlight.

## Motivacion

La motivacion del proyecto es unir una experiencia visual atractiva con una arquitectura tecnica seria. La perfumeria permite trabajar con datos muy interpretables para el usuario: notas, sensaciones, ocasiones, temporadas y presupuesto.

El resultado busca parecerse a un asesor olfativo premium, no a un formulario tecnico.

## Publico objetivo

PerfumIA esta pensada para personas que quieren comprar o descubrir un perfume para diario, trabajo, citas, noche, eventos o una temporada concreta, aunque no sepan explicar todavia que notas o familias olfativas prefieren.
